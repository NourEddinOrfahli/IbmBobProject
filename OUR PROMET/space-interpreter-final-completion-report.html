8. Remaining Limitations

  • Conversation history persistence: Chat history is session-only (not persisted across page reloads). Architecture is ready for future database-backed persistence.
  • Vision live integration: NOT VERIFIED — EXTERNAL DEPENDENCY. Requires a valid OPENROUTER_API_KEY and a vision-capable model (OPENROUTER_VISION_MODEL). All code paths verified by 44 mock-based tests.
  • Stories search is client-side: Filters already-loaded stories. Backend full-text search would require a future database/index.
  • No user authentication: Favorites use localStorage only. Suitable for MVP; ready for future user accounts.
